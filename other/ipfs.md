# IPFS

IPFS 是为分布式 Web 提供动力的一种点对点超媒体协议，旨在通过使网络可升级、有弹性和更开放来保存和增长人类的知识。

![create-mining](../.gitbook/assets/other/ipfs/ipfs_01.png)

### 点击上传按钮，选择本地文件/图片进行上传。
